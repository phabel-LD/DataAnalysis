# Data Analysis Projects

**Author:** Phabel Antonio López Delgado

This repository is a **historical archive** of data analysis projects conducted primarily for theses, research papers, and internal reports. The analyses are written in **R Markdown** (`.Rmd`) and span several years (2023–2025).

The repository serves as a record of applied data analysis work, covering exploratory data analysis, statistical modelling, data visualisation, and reporting. It is **not** intended as a production‑ready codebase, but rather as a collection of reproducible (or historically documented) analyses.

---

## Repository Structure
```text
DataAnalysis/

│   ├── 2023/
```

Each year folder contains R Markdown files, along with any supporting data or output files. The naming convention and organisation within each year reflect the specific projects and workflows at that time.

---

## Contents Overview

The analyses cover a range of domains, including:

- **Health data analysis** – often related to ISSSTE (Mexican Institute of Social Security).
- **Statistical modelling** – regression, survival analysis, hypothesis testing.
- **Data visualisation** – exploratory plots, dashboards, and report generation.
- **Machine learning** – classification, clustering, and predictive modelling (where applicable).

Detailed descriptions and context for each project are typically found within the respective `.Rmd` files.
